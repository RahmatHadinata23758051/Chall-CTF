# NullWake

Category: Forensics

Difficulty: Insane

The workstation image was not preserved cleanly. What survived is a tarball of userland debris pulled from a machine that somebody clearly tried to sanitize after staging prompt fragments through temporary caches, drafts, and session junk. They were sloppy enough to miss things, but not sloppy enough to leave the answer sitting in one place for tourists.

You are looking for what the user thought they deleted. Expect stale application data, residue from aborted exports, and traces that only make sense once you stop treating every artifact like a self-contained confession. If you chase the loudest clue first, it will waste your time.

Recover the flag from the evidence bundle.
